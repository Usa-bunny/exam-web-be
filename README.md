## 🚀 Getting Started

### Installation
1. Clone the repository:
~~~bash
git clone https://github.com/Usa-bunny/exam-web-be.git
cd exam-web-be
~~~
2. Setup
```bash
npm run migrate
npm run seeder
npm run dev
```
