## 🚀 Getting Started

### Installation
1. Clone the repository:
~~~bash
git clone https://github.com/Usa-bunny/exam-web-be.git
cd exam-web-be
~~~
2. Setup .env
```env
PORT=3000
JWT_SECRET=your_jwt_secret
```
4. Setup database
```bash
npm run migrate
npm run seeder
```
4. Run
```bash
npm run dev
```
